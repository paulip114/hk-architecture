# Document library

These are the official and reference documents used to check the rules in this repo. They are not published here because they belong to their owners, and some are paid. Download your own copies from the links, and check for a newer version first.

The repo owner keeps local copies in `docs/document library/`, which Git ignores for PDFs and for PNGs in that folder. Do not commit these files or quote paid documents. Use clause references and paraphrase instead.

Links were checked on 2026-11-06. The eLegislation site needs a browser, so those links were checked by address pattern and not by opening each document.

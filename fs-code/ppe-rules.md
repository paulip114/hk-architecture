# Use Classification 5a – places of public entertainment (FS Code Part B s.3 B19–B28; Part C C18)

Draft working rules. Data is embedded in `../tools/ppe_check.py`.

## Exemption and exits
- B19.2: small premises can be exempt from the special provisions. Check the exemption against the code text.
- B20: keep thoroughfares clear.
- B21: exits by Table B2 where the floor is below 12 m; Table B5 at 12 m or more.

## Tiers and stairs
- Tier gradient ≤ 35°, headroom ≥ 3 m.
- B23 stairs:
  - Tread 280 mm, riser 150 mm.
  - 3–16 steps per flight.
  - A turn is needed above 12 steps.
  - No more than 2 flights without a turn.

## Foyers and siting
- Foyer (B27.8): 0.5 m² × seats/6.
- Basement cinemas (B27.3(f)): seats/3.
- B27.1–B27.5: cinemas in multi-storey buildings and basements (location, separation, exits independent of the rest of the building).

## Fire separation (C18)
- C18.1(d): projection room at FRR -/60/60.
- C18.2: theatre stage separation.

## Linings
- Linings in auditoria are Class C or better (Part E, E13/E14).

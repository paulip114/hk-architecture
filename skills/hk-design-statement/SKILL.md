# HK design statement

Use when the user asks for a design statement, design rationale, concept text, planning statement, competition write-up, or a project statement for a portfolio or the professional interview.

## Before starting
1. Read `/mnt/project-files/architect-kb/design/statements/design-statement-guide.md`.
2. Pick the template in `design/statements/templates/` from the table in section 1 of the guide (s16, GBP, heritage, competition, portfolio). If the reader is unclear, choose the most likely one and say so.

## Gather
- Project facts: site, uses, GFA / PR / height / storeys (take them from a `bpr_check` or `massing_study` report so figures match), drawings or images.
- The audience's limits: word count, assessment criteria, required sections.
- The idea: ask for the one-sentence parti if the user has one; otherwise propose two.

## Write
- One claim, three design moves, each with evidence (a figure or a drawing reference).
- Neutral tone for TPB / BD / Lands; persuasive but concrete for competitions.
- Cite ordinances, PNAPs and TPB guidelines by number; mark anything unverified as 待核.
- If a movement or master is cited, use `design/movements/masters.md` and say which principle is borrowed and how it is applied.
- Save to `/mnt/project-files/projects/<name>/` and run the checklist in section 5 of the guide before handing over.
- State: draft for review and signature by an Authorized Person.

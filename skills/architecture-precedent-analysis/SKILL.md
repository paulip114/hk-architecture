# Architecture precedent analysis

Use when the user asks about an architectural movement, a master architect, what style a building is, how to read or analyse a building, or for precedents to support a design.

## Before starting
Read `/mnt/project-files/architect-kb/design/movements/reading-method.md`, then the relevant parts of `movements.md` and `masters.md` in the same folder.

## Do
1. Context: period, place, client, technology, debates of the time.
2. Parti in one sentence.
3. Read the building with the ten questions in `reading-method.md` and pick the 3–4 Clark & Pause categories that matter most; describe the diagrams you would draw (or draw them as SVG if asked).
4. Place it in a movement and name contemporaries; if classification is debatable, say "can be read as … because …".
5. Lessons for Hong Kong: one principle and how it would apply to a dense HK site, linking to `design/massing/` or the B(P)R / FS Code rules where relevant.
6. For a precedent list: 3–5 buildings, each with the principle borrowed.

## Care
- Dates and attributions: use the notes; anything marked 待核 or not in the notes must be stated as unverified. Do not invent works.
- Answer in the user's language; keep English names of buildings and architects.

# 僭建物（Unauthorised Building Works, UBW）

標記：✅ 已喺 BD 網站核實（2026-11-05），⚠️ 未核實。

來源：
- https://www.bd.gov.hk/en/safety-inspection/ubw/index.html
- https://www.bd.gov.hk/en/safety-inspection/ubw/enforcement/index.html

## 1. 定義 ✅
未經 BD 事先批准而對建築物進行嘅加建或改動，以及冇跟小型工程簡化程序進行嘅工程。

## 2. 須執法取締嘅僭建物（Actionable UBW）✅
以下項目 BD 會發法定命令要求清拆：
1. 對生命財產有明顯危險或迫切危險，包括室內項目，例如不安全劏房工程、阻塞走火通道、嚴重滲水或超載。
2. 新建僭建物（不論樓宇何時落成），法定豁免工程除外。
3. 外部項目：天台、平台、天井、後巷，以及外牆伸出物。**不包括** 家居小型工程檢核計劃、招牌檢核計劃同其他小型附加設施涵蓋嘅項目。
4. 嚴重衞生或環境滋擾，例如渠管駁錯。
5. 大型獨立項目。
6. 大規模行動目標樓宇內嘅指定類型。
7. 擅自改動已獲 GFA 寬免嘅綠化及康樂設施（露台、空中花園、平台花園等）。

## 3. 執法工具
| 工具 | 內容 | 狀態 |
| --- | --- | --- |
| 清拆令（s.24） | 向業主發法定命令清拆；命令會喺土地註冊處註冊，影響業權 | 命令及註冊 ✅；條文編號 s.24 ⚠️ |
| 警告通知 | 唔屬須執法類別嘅僭建物可發警告通知，亦可註冊於業權 | ✅ |
| 地盤監察後命令 | s.23、s.24A 命令（ADM-13 para 2 提及） | ✅（提及存在） |
| 檢控 | 不遵從命令屬刑事罪行；罰則 ⚠️ 未核實（一般講法：s.40(1BA) 罰款 $200,000 及監禁一年，另每日罰款） | ⚠️ |
| 代做並收費 | BD 可代業主做工程後收回費用及附加費 | ⚠️（MBIS 指引有寫最多 20% 附加費，UBW 未核實） |

## 4. AP 實務
- **買樓 / 盡職審查**：比對 OP 圖則、批准圖則同現場，列出疑似僭建；查土地註冊處有冇註冊命令。
- **收到命令後**：委任 AP / RC → 評估可否申請追認（入則把現有工程正規化）或者清拆 → 清拆工程按命令要求通知 BD → 完工證明 → 申請解除命令註冊。⚠️ 程序細節未核實。
- **追認入則**：當作加建改動工程，交 BA5 / BA8（或符合小型工程就按 MWCS），現有結構要驗證（開孔驗鋼筋、荷載測試）。
- **新界豁免屋宇**：另有執法安排，見 https://www.bd.gov.hk/en/safety-inspection/ubw/UBW-in-new-territories-exempted-houses/index.html ⚠️ 未讀取。

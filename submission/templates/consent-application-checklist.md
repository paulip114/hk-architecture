# 清單：申請同意動工（BA8 / BA8A）及動工

標記：✅ 已核實 BD 網站，📜 已對 Cap. 123 / 123A 原文（來源見 `submission/bd-submission-process.md` 第 4 節），⚠️ 未核實。草稿，要 AP 覆核。

## A. 申請前
- [ ] 有關圖則已批准（或同步申請 BA8A）✅
- [ ] 分階段審查：申請上蓋同意前已完成 Stage II（2023-03-31 後首次遞交嘅新發展）✅ ADM-19
- [ ] 毗鄰地段 / 樓宇業主同意（如工程影響佢哋）✅ ADM-2
- [ ] 地契：BA 批准唔豁免地契；需要時已取得地政總署同意 ✅ s.14(2)
- [ ] 其他部門要求（例如路政署挖路、運輸署臨時交通安排、港鐵保護範圍）⚠️

## B. 表格及文件
- [ ] BA8（或 BA8A 同步）✅
- [ ] 註冊承建商資料：BA10 委任、動工通知及承諾書 ✅
- [ ] 監工計劃 SP（及 SPA）✅
- [ ] 圍板、有蓋行人道、門架：BA19 許可 ✅；圍板圖則 ✅ ADM-19 para 34
- [ ] 承建商工棚：BA18 ✅
- [ ] 拆卸工程：BA20 委任技術適任人員 ✅
- [ ] 預防性工程（如需要）已完成或有方案 ✅ ADM-19 para 34

## C. BA8A 同步申請條件（ADM-19 para 34）✅
- [ ] 除擴展式基腳（開挖 ≤ 4.5 m）外無其他地基工程，亦無重大岩土內容
- [ ] 動工前唔需要預防性工程
- [ ] reg 8 所需圖則已交齊
- [ ] 附監工計劃、圍板圖則
→ 跑 `tools/submission_timeline.py`（consents[].concurrent = true）自動檢查。

## D. 期限
- [ ] 同意處理期 28 日（B(A)R reg 32(3)）；非同步時由批准日起計 ✅
- [ ] BA10 動工通知：動工前**不少於 7 日**（B(A)R reg 20(1)）📜
- [ ] TCP 委任通知（需要監工計劃時）：動工前不少於 7 日（reg 20(2)）📜
- [ ] 已交監工計劃書，否則唔會當作同意（s.14A）📜
- [ ] 同意後 **3 個月內** 要動工，停工唔可以超過 3 個月，否則同意當作撤銷，要 BA9 續期（s.20）📜
- [ ] 已同意工程嘅修改或加建：書面申請連圖則及同意通知，28 日（reg 33）📜

## E. 動工後
- [ ] 批准圖則、工序、BA 條件交 RC 存放地盤，有需要時解釋及翻譯 ✅ ADM-13
- [ ] TCP 按監工計劃巡查，紀錄用 Form A；不符合用 Form B ✅
- [ ] 違規盡快通知 BA ✅ ADM-13 para 5(g)
- [ ] 修改設計：判斷係咪輕微修訂（ADM-19 Appendix G），唔係就先交修訂圖則 ✅
- [ ] 更換 RC：BA11 + 新 BA10 ✅
- [ ] AP 暫時唔能履行職務：BA21 ✅

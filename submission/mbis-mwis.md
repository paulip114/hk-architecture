## 1. 比較表
| 項目 | MBIS 強制驗樓 | MWIS 強制驗窗 |
| --- | --- | --- |
| 適用樓齡（由 OP 發出日期計） | 30 年或以上 📜 s.30B(1)、(2) | 10 年或以上 📜 s.30C(1)、(2) |
| 豁免 | 不超過 3 層嘅住宅樓宇 ✅ | 同左 ✅ |
| 週期 | 每 10 年 ⚠️ | 每 5 年 ⚠️ |
| 預先通知至法定通知 | 最少 6 個月 ✅ | 最少 2 個月 ✅ |
| 檢驗人 | 註冊檢驗人員（RI），要親自檢驗 ✅ | 合資格人士（QP）：AP、RSE、RI、RGBC，或已註冊窗戶小型工程嘅 RMWC ✅ |
| 修葺人 | RGBC 或 RMWC，由 RI 監督 ✅ | RGBC 或 RMWC，由 QP 監督 ✅ |
| 範圍 | 公用部分、外牆、伸出物 / 招牌；結構、消防安全（走火、消防救援通道、耐火結構）、排水系統、僭建物 ✅ | 所有窗及玻璃百葉（個別單位及公用部分），包括窗牆；不包括室內玻璃間隔、地下舖面櫥窗；幕牆歸 MBIS ✅ |
| 通知內容 | BA 可指明委任 RI、完成檢驗、完成修葺嘅最後日期；通知可喺土地註冊處註冊 📜 s.30B(7)、(9) | 同左，委任 QP 📜 s.30C(5)、(7) |
| 違規 | 無合理辯解：第 5 級罰款（$50,000）及監禁 1 年，另每日 $5,000 📜 s.40(1BC) | 第 4 級罰款（$25,000）及監禁 3 個月，另每日 $2,000；BA 起訴前要先發定額罰款通知書（指引：$1,500）📜 s.40(1BD)、(1BE)、附表 7 |
| BD 代做 | 唔遵從可無需再通知而代做（s.30B(10)），收回費用及不超過 20% 附加費（s.33）📜 | 同左（s.30C(8)）📜 |

## 2. MBIS 流程
```
BD 預先通知（≥6 個月）→ 法定通知
 → 業主 / 法團委任 RI（MBI1）
 → RI 親自檢驗（訂明檢驗）
 → 7 日內交檢驗報告、檢驗證明書、修葺建議 ✅
     ├ 唔使修葺：MBI3a
     └ 要修葺：MBI3 → 委任 RGBC / RMWC 修葺（訂明修葺），RI 監督
 → 完成：MBI4 修葺證明書
 → 如檢驗 RI 冇監督修葺：MBI5 無業務關連證明書
```
- 深入調查（Detailed Investigation）要 BD 先批准建議先可以做。✅
- 完成期限按法定通知所寫 ✅（指引冇固定日數）。
- 臨時換 RI：MBI2。✅
- 驗樓時發現僭建物要報告（範圍包括 UBW）。✅

## 3. RI 檢驗清單（摘自指引 Annex I 範圍）
- [ ] 外牆飾面、批盪、紙皮石、混凝土剝落
- [ ] 伸出物、招牌、簷篷、冷氣機架
- [ ] 結構構件：裂縫、鋼筋外露、變形
- [ ] 消防安全：走火通道、防火門、耐火結構、消防救援通道
- [ ] 排水：外牆渠管、公用渠管槽、地下及地面渠道
- [ ] 僭建物
- [ ] 幕牆（屬 MBIS）

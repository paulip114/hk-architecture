## 1. 整體流程

```
[入則前]  土地 / 規劃查冊 → 委任 AP/RSE/RGE（BA4）→ 入則前查詢 / 會議（可選）
   │
[圖則]    GBP 首次遞交（BA5）經 ESH → BD 同步轉介各部門（集中處理）
   │      第 45 日可查詢是否基本可接受
   │      60 日內：批准 / 不批准（列出不批准項目）
   │      不批准 → 修訂後重新遞交（較短法定期限 ⚠️）
   │      結構、地基、排水、地盤平整圖則各自遞交及批核
   │
[同意動工] BA8（或與批核同步 BA8A）→ 28 日（B(A)R reg 32(3)）
   │      委任註冊承建商及通知動工（BA10）、監工計劃（SP）
   │
[施工]    修訂圖則（amendment plans）要先批後做；輕微修訂按 ADM-19 Appendix G 判斷
   │      分階段 GBP：Stage II 要喺申請上蓋同意之前；Stage III 要喺申請 OP/TOP 之前
   │
[完工]    BA13（新建築物 OP）/ BA12（暫時佔用許可證 TOP）/ BA14（不涉新建築物）
   │      聯合驗樓（BD + FSD 等）→ 發 OP（⚠️ 14 日內）
   │
[OP 後]   地政總署滿意紙 / 合約完成證明（地契，另行處理）、OP 後修正工程表格（Appendix I–IV）
```

## 2. 入則前

1. **地盤資料**：地契條款、分區計劃大綱圖限制、地盤面積證明（PNAP ADM-21 Site Parameters, Documentary Proof）、街道闊度、地下設施（港鐵保護範圍等）。
2. **委任**：業主以 **BA4** 委任 AP、RSE、RGE（如需要）。✅（BD 表格頁）
3. **入則前查詢**：AP 可就不確定事項向 BD 查詢，每個問題要寫成具體命題。✅（ADM-2）
   - 預先查詢的保證信：一般 45 日內回覆；一般查詢服務四星期內回覆。✅（ADM-19 para 4、21）
4. **豁免 / 變通（s.42）**：用 **BA16**，寫明特殊情況同理由，附 ADM-2 Appendix D1、E 要求資料。BA 可以用 **BD 106** 附加條件；條件要喺修訂圖則反映，交完工證明書時要附有效 BD 106 清單（ADM-2 Appendix F1）。✅（ADM-2）

## 3. 一般建築圖則（GBP）遞交

### 3.1 遞交
- 表格 **BA5**：申請批准建築工程 / 街道工程圖則，連同擬備圖則證明。✅（BD 表格頁）
- 經 **電子遞交中心（ESH）** 遞交，ESH 同時將圖則送 BD 同有關部門。紙本遞交要交足份數，否則轉介會延誤。✅（ADM-2）
- 紙本份數（ADM-2）：BA 兩套簽署上色；消防處兩套（某些消防條例下三套）；規劃署地區規劃專員一套；地政總署地政專員市區一套（某些地契條款下兩套，新界兩套）；岩土評估報告兩套。✅
- 要附 GFA 寬免明細（ADM-2 Appendix G）。✅
- 圖則顏色跟 ADM-9；電子格式跟 ADM-17（未逐條核實）。

### 3.2 集中處理（Centralised Processing）✅ ADM-2
- BD 轉介有關部門，喺法定處理期內收集意見。
- 一般轉介：消防處、規劃署、地政總署。視乎地盤再轉介（Appendix A）：土力工程處、渠務署、港鐵、路政署、運輸署、海事處、機電工程署、環保署、勞工處、古物古蹟辦事處等。
- **只有屬《建築物條例》範圍、而且屬 ADM-19 所列「基本事項」嘅意見，先會成為不批准理由**；其他部門意見只作參考轉交。遲到嘅意見會另函或經 ESH 通知。
- 意見有衝突：《建築物條例》事項由 BA 裁決；其他事項交返有關部門，BD 可召開會議協調。

### 3.3 基本事項（ADM-19）✅
GBP 只審查基本事項，非基本事項「不會被審查，亦不會列作不批准項目」（para 12）。
- GBP（Appendix A）：密度、安全、衞生及環境、主要相關法例事項。
- 上蓋結構主框架（Appendix B、B1）：穩定性及框架、耐火時效、荷載、材料。
- 排水（Appendix C）：排放方式、地下渠道佈局、維修通道。
- 拆卸、地盤平整、地基、挖掘及側向支撐（Appendix D）。

### 3.4 分階段簡化審查（Staged Curtailed Check）✅ ADM-19 para 14–20
適用於 2023-03-31 之後首次遞交 GBP（或重大修訂）嘅新發展項目。
| 階段 | 時間 | 內容 |
| --- | --- | --- |
| Stage I | 首次批核 | 只批 Stage I 項目 |
| Stage II | 申請上蓋同意之前 | 以修訂圖則遞交，註明 "This set of plans is submitted for Stage II Curtailed Check" |
| Stage III | 申請 OP / TOP 之前 | 其餘項目 |
特殊情況可要求提早做 Stage II。

### 3.5 處理期限
| 事項 | 期限 | 狀態 |
| --- | --- | --- |
| 首次遞交圖則：批准或不批准 | 60 日 | ✅ ADM-2 提及「法定 60 日」；條文 s.15 ⚠️ |
| 重新遞交 / 修訂圖則 | 30 日 | ⚠️ 未核實 |
| BA 逾期未通知是否當作批准 | 條例有「當作批准」機制 | ⚠️ 未核實，唔好依賴 |
| 第 45 日查詢是否基本可接受 | 遞交後第 45 日 | ✅ ADM-2 |
| 已於 60 日內列出嘅不批准項目，重交時一般唔會加新項目 | — | ✅ ADM-2 |
| 撤回並重新遞交（W&R）：法定處理期重新起計；同一遞交一般最多兩次；要書面並附理由 | — | ✅ ADM-22 |
| 簡單加建改動工程快速同步批核及同意 | 30 日 | ✅ ADM-19 para 35 |
| 幕牆 / 窗牆 / 外牆覆面維修快速處理 | 30 日 | ✅ ADM-19 para 38 |
| 兩層貨倉同步批核及同意 | 45 日 | ✅ ADM-19 Appendix I |

日數計法（是否不計首日、假期）⚠️ 未核實，要對《釋義及通則條例》（Cap. 1）。工具 `tools/submission_timeline.py` 用「遞交日 + N 個曆日」，係保守估算。

### 3.6 不批准理由
不批准理由列於條例 s.16(1)（例如違反條例或規例、圖則資料不足）。ADM-14 引用 s.16(1)(c) 及 s.16(1)(i)。✅ 其餘各款 ⚠️ 未核實。

### 3.7 輕微修訂（ADM-14）✅
- 可以喺 BD 由 AP 即場修改並簽署認證（BD 通常先同設計團隊面談）。
- 替換頁：修改要清楚註明並逐項認證，同個案主任協定交回日期，**不多於兩個工作天**。
- 抽走部分文件修改：書面要求並承諾兩個工作天內交回。
- ESH：用 "Revised Submission" 功能，先同個案主任協定。
- 逾期唔交：可能按 s.16(1)(i) 及/或 s.16(1)(c) 不批准。

## 4. 同意動工（Consent to Commence）

- 條例 s.14(1)：未得 BA 批准圖則及同意動工，不得展開建築工程。⚠️ 條文未核實（但係基本原則）。
- **BA8**：申請同意展開及進行建築 / 街道工程。✅
- **BA8A**：與批准圖則同步申請同意。✅
- **BA9**：申請續期同意。✅（失效期限 ⚠️ 未核實）
- 處理期：**B(A)R reg 32(3) 28 日**；如批准圖則唔係同步發出，由批准日起計。✅ ADM-19 para 39(c)
- 同步申請（BA8A）條件（ADM-19 para 34）✅：
  - 除開挖深度 4.5 m 或以下嘅擴展式基腳外無其他地基工程，亦無重大岩土內容；
  - 動工前唔需要預防性工程；
  - 已交齊 reg 8 所需圖則；
  - 附監工計劃、圍板圖則等支持文件。
  - 同步申請嘅生效日係批准日；圖則未批唔會處理（para 39(a)(b)）。
- 批准唔代表取得土地業權，亦唔豁免地契條款（s.14(2)）；涉及毗鄰地段 / 樓宇要另取業主同意。✅ ADM-2

### 4.1 動工及地盤監督
- **BA10**：委任註冊承建商（RC）、通知動工、RC 承諾書。✅（遞交時限 ⚠️ 未核實，常見做法係動工前最少 7 日）
- **BA11**：RC 終止委任通知，連同已完成部分證明書。✅
- **SP / SPA / Form A / B / C**：監工計劃、技術適任人員（TCP）紀錄、不符合及修正報告。✅（BD 表格頁）
- 批准圖則、工序、BA 條件要發給 RC 存放地盤，有需要時要解釋同翻譯；違規要「盡快」通知 BA；不滿意之處要「即時」修正。✅ ADM-13 para 5
- 監工計劃、TCP 級別按《建築工程及街道工程的監工技術備忘錄》⚠️ 未讀取。
- **BA7**：意外或緊急情況後需即時進行工程嘅通知。✅
- **BA15**：擬將建築物用途作重大改變嘅通知。✅（通知期 ⚠️ 未核實，一般講法係一個月前）

### 4.2 修訂圖則（Amendment Plans）
- 施工期間嘅修改一般要遞交修訂圖則，先批後做。
- 輕微修訂：要按 s.42(1) 變通 reg 33(1)（ADM-19 para 29）；修訂要記錄並存放地盤辦事處（para 31）。✅
- **以下唔算輕微修訂**（ADM-19 Appendix G 節錄）✅：排水挖掘深過 3 m；非大直徑鑽孔樁數目增加超過 5%；大直徑鑽孔樁增加超過 15%；地盤平整水平改變超過 1 m；擋土高度改變超過 1 m。

## 5. 完工及佔用許可證

### 5.1 表格 ✅（BD 表格頁）
| 表格 | 用途 |
| --- | --- |
| BA12 | 新暫時建築物或新建築物部分完工證明書，申請暫時佔用許可證（TOP） |
| BA13 | 新建築物完工證明書，申請佔用許可證（OP） |
| BA14 | 不涉及新建築物嘅工程或街道工程完工證明書 |
| BA14A / 14B | 拆卸工程完工證明書（一般 / 簡化程序） |
| BA14C | 不涉及新建築物工程完工證明書（簡化程序） |

### 5.2 申請 OP / TOP 前要做齊（ADM-19、ADM-2）✅
- 所有修訂已獲批准及同意；最新 GBP、結構、排水、地盤平整圖則要互相吻合（ADM-19 para 3）。
- 必要圖則未獲批准，BA 可按 s.21(6)(a) 拒發 OP/TOP（para 14）。
- 2021-08-31 之後取得上蓋同意嘅項目，符合資格嘅小型建築工程要先納入圖則（para 41）。
- 交所有已批修訂嘅綜合數碼檔（para 25）。
- 分階段審查嘅 Stage III 要已完成。
- 附 GFA 及泊車位摘要（ADM-2 Appendix H），BD 喺發 OP 後公佈。
- s.42 條件（BD 106）已反映喺修訂圖則，並附有效 BD 106 清單（Appendix F1）。

### 5.3 OP 程序
- 遞交 BA13 / BA12，連同 RC、AP、RSE、RGE 嘅完工證明。
- BD 聯同消防處等部門驗樓。各部門相關證明（例如消防裝置、升降機及扶手電梯、供水、排水接駁）⚠️ 未逐項核實，見 `submission/templates/op-application-checklist.md`。
- BA 處理 OP 申請期限：14 日 ⚠️ 未核實。
- OP 亦可以 W&R（ADM-22），法定期重新起計，最多兩次。✅
- OP 後修正工程：用 Appendix I–IV 表格通知開工、完工、成員終止、更換成員。✅（BD 表格頁）

### 5.4 OP 之後（非 BD）
- 地政總署：滿意紙（Certificate of Compliance）/ 地契條款履行，另行申請 ⚠️。
- 物業轉讓、預售樓花同意書（地政總署）唔喺呢份範圍。

## 6. 常見失誤（考試及實務）
1. 以為部門意見全部都係不批准理由。只有《建築物條例》下嘅基本事項先係（ADM-2）。
2. 第 45 日冇主動查詢，到第 60 日先知唔批。
3. W&R 用多過兩次，或冇書面理由。
4. 輕微修訂超出 Appendix G 門檻都當輕微處理，結果 OP 卡住。
5. 申請 OP 時修訂圖則未批齊或者各套圖則唔吻合。
6. 忘記 BD 106 條件要反映喺圖則。
7. 混淆 BA 批准同地契批准：BA 批准唔豁免地契（s.14(2)）。

# 點樣「讀」一座建築：分析方法

目標：睇一座建築 15 分鐘，講得出佢嘅主張、用咗乜手法達成、同屬於邊個流派，再畫得出三張分析圖。適用於研究先例、寫設計說明、面試講作品。

## 1. 十個問題（順序讀）

| # | 問題 | 睇乜 | 畫乜 |
| --- | --- | --- | --- |
| 1 | 背景 | 年代、地點、氣候、業主、技術、當時嘅爭論 | 位置圖 |
| 2 | 主張 (parti) | 一句講晒嘅大概念 | 一張 30 秒草圖 |
| 3 | 地盤關係 | 軸線、入口方向、地形、景觀、街道 | 總圖＋箭咀 |
| 4 | 幾何同秩序 | 格網、軸線、對稱／平衡、比例（黃金比、Modulor、整數比） | 平面格網疊圖 |
| 5 | 體量同層級 | 加法／減法、主次、重複與獨特、單元與整體 | 軸測分解圖 |
| 6 | 結構同建構 | 結構系統、跨度、承重同圍護嘅分離、接駁 (tectonics) | 結構軸測 |
| 7 | 流線同序列 | 入口、前導空間、轉折、高潮、服務流線 | 平面上路線 |
| 8 | 光 | 直射／漫射、天窗、深度、時間變化 | 剖面光線 |
| 9 | 物料同觸感 | 真實性、質感、老化、工藝 | 細部放大 |
| 10 | 服務與被服務 | 機電、樓梯、核心筒點樣同主空間分開 | 平面著色 |

## 2. Clark & Pause 分析類別（Precedents in Architecture）

Structure、Natural light、Massing、Plan to section、Circulation to use-space、Unit to whole、Repetitive to unique、Symmetry and balance、Geometry、Additive and subtractive、Hierarchy。每座建築揀最有代表性嘅 3–4 項畫，唔使全部。

## 3. 由手法認流派（速查）

| 見到 | 多數係 |
| --- | --- |
| 柱式、山花、對稱、三段式立面 | 古典／新古典 |
| 尖拱、扶壁、垂直線條 | 哥德復興 |
| 自由平面、底層架空、水平長窗、天台花園、白色 | 現代主義（Le Corbusier 五點） |
| 鋼同玻璃、精準細部、通用空間 | Mies／國際風格 |
| 水平延伸、出挑、同地景交織、天然物料 | 有機建築（Wright、Aalto） |
| 清水混凝土、厚重體量、結構外露 | 粗獷主義 |
| 可加減嘅單元、巨構、未來擴展 | 新陳代謝派 |
| 結構同機電外露、預製、可變 | 高技派 |
| 歷史符號、拼貼、諷喻、顏色 | 後現代 |
| 斜面、碎裂、失衡、扭曲 | 解構主義 |
| 連續曲面、漸變、演算法生成 | 參數化 |
| 本地物料同氣候回應＋現代語言 | 批判性地域主義 |
| 光、靜、物料本質、極少構件 | 極簡／現象學 |
| 院落、軸線、斗拱、坡屋頂、冷巷 | 中國傳統／嶺南 |

## 4. 一頁分析表（範本）

```
建築：            建築師：            年份：        地點：
流派：            同代參照：
一句主張：
三個手法：1.                 2.                 3.
圖：[總圖] [平面格網] [剖面光線] [軸測體量]
對香港設計嘅啟示：
同我項目嘅關係：
```

## 5. 考試同面試用法

- 講先例時：「我參考咗 X 嘅 Y 原則，因為本項目同樣面對 Z，所以我做咗 W。」四個元素齊晒先算。
- 唔好只講風格名詞；考官要聽到你明白原則同取捨。
- 每個大師準備一個可以喺香港應用嘅原則（見 `masters.md` 每段最後一行）。

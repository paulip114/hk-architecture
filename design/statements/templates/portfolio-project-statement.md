# [項目名稱] – Project Statement for Portfolio / Professional Interview 作品集及專業面試

> 範本。專業面試考官想知：你本人做過乜、點解咁決定、法規、合約、成本、安全同專業操守點處理。用第一身講你自己嘅角色，唔好只講公司。

## 1. 項目概況（3–4 行）
類型、地點、規模 (GFA、層數)、合約形式、你參與嘅階段同時間、你嘅角色同匯報對象。

## 2. 我嘅角色
| 階段 | 我負責 | 我決定咗乜 |
| --- | --- | --- |
| 可行性／體量 | | |
| 規劃申請 | | |
| 圖則入則 (GBP) | | |
| 招標及合約 | | |
| 施工及驗收 (OP) | | |

## 3. 設計：一個主張，兩三個關鍵決定
每個決定用「問題 → 選項 → 決定 → 結果」講。

## 4. 法規挑戰
例：GFA 寬免爭議、走火距離、EVA、豁免申請。講法規編號、你點同屋宇署／消防處溝通、結果。

## 5. 合約同造價
合約形式（例如 HKIA 標準形式、政府合約）、變更指令、索償、成本控制。你做過乜。

## 6. 專業操守同責任
有冇遇過利益衝突、安全問題、客戶要求同法規衝突？你點處理，依據乜（ARB／HKIA 專業守則）。

## 7. 反思
如果再做一次會改乜，學到乜。
